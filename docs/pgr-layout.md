## 本站采用（只采用结构，不搬素材）

1. 首屏是指令台 HOME：左操作列表、右预览图。选项排好，等人选下一步。不是一进站就推人物。
2. 机体档案 DATA 变成其中一个入口。进去后灰鸦五人按全高排队，点谁谁走上前。立绘不发灰、不裁脚。
3. 档案字段沿用 Wiki 的短字段（阵营 / 职阶 / 关联），不要再堆继续阅读大卡片。
4. 开机动效改成官网同族：左侧竖菜单从上入、底栏从下入、立绘淡入；换人保留扫光换帧。主导航不再用吸顶横栏，避免挡住区块标题。
5. 阅读进度、搜索、发布仍保留，但退出首屏主视觉。
6. 观看层按实机旁白页：全屏 CG、右上回顾/自动/SKIP/名词解释、底部横线旁白、右下 NEXT。主线普通关播本地存档对白。第一次点击补全当前句，第二次进下一句。台词里的词条可点开短释义；弹幕和批注收到回顾面板。完整定位见 `docs/story-station.md`。
7. 首屏以下不再用雷达图/卷宗表。剧情回顾用分类页签 + 章节 CG 网格；关卡页用宽 CG + 播放条；讨论用玩家发帖流。选中色为正红。
