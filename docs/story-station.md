# 剧情站定位（调研，先不改界面）

采集：2026-09-11。对照用户主线一览长图、BWiki「剧情回顾 / 序章 / 序章01」、库街区主线目录、GRAY RAVENS `Template:Dialogue`。不搬官方完整剧本。

## 人来看什么

BWiki 序章页评论已经说清楚，不是猜的：

- 血清不够，关卡打不完，想回头看剧情却要重打。
- 战斗、解密把剧情切开，想一口气看完。
- 萌新被剧情吸引，需要一条能停、能续、能回看的航线。

所以本站主产品是**过剧情 + 回看 + 讨论**，不是机体展板、不是攻略站。进站后先到指令台（左操作、右预览），选项排好等人选；机体档案是其中一个入口，不是首页。DATA 里灰鸦五人按全高排队，点谁谁走上前。

## 入口该长什么样（对照，不自造）

BWiki「剧情回顾」= 用户长图：深色分类页签 + 章节 CG 封面网格。点进「序章」后是：宽封面 CG、完整关卡数、横排关卡按钮（进入序章 / 0-1 汇合 / 0-2 突围 / 0-3 深红）带播放箭头。

本站封面带已改成这套章节 CG（序章 + 01 涂鸦艺术），不是机体肖像墙。已落地封面见 `docs/assets.md`。

## 阅读层该长什么样（对照，不自造）

三套公开还原，优先级不同：

1. **游戏内旁白演出（实机截图）**：全屏 CG、右上「回顾 / 自动 / SKIP」、底部横线 + 波形、右下 NEXT。本站观看层按此落地。
2. **GRAY RAVENS `Template:Dialogue`**：国际 Wiki 用来还原角色对白。左对话头像 + 名字条 + 台词；旁白无头像。本站角色句仍用这条信息结构，但观看层不再叠头像框。
3. **BWiki `zs-DialogBox`**：文字回顾。名字右对齐表头 + 台词单元格。方便检索，不是游戏内演出。

当前观看层按实机旁白页落地：章节 CG 铺满，无前景立绘、无左头像框。右上为回顾 / 自动 / SKIP / 名词解释；底部一条白线 + 短波形，台词叠在线下方；右下 NEXT。点击/空格第一次补全当前句，第二次进下一句。主线普通关播本地存档对白；台词里的公开设定词可点开短释义（G 键开关）。弹幕、批注、上一句收到回顾面板里。恢复点仍写 `mindtrace.play`。主导航按官网改成左侧竖菜单，不再用吸顶横栏挡标题。

进站有一层节点连线接入（黑底红线，过境字标）。借莱茵生命那种「连线打亮再进系统」的节奏，不套明日方舟标识。每次刷新都播，SKIP / 点击 / Esc 可跳过。减弱动画时只留静态图。

## 讨论怎么放（玩家发帖，不造图书管理员）

战双没有「图书管理员」角色。最接近的公开 AI 是**格式塔**：黄金时代超级 AI，现为空中花园最高管控 AI。它不是站内客服，也不能拿来当论坛主持人。

本站讨论层按玩家发帖：看完一关可以跟帖，讨论区是帖子流。不内置扮演格式塔的 AI。

## 弹幕 / 畅所欲言放哪

要留住人，是**边看边说**，不是看完再去评论区。

- 过剧情时：弹幕叠在对白层上，按关卡，可关；本机可发一条，写入 localStorage。
- 过完一关：批注、解读、剧透开关（已有本地发布，可接到关卡下）。
- 回看：主线 / 间章 / 活动 / 好感分页 + 搜索。

## 素材边界

- 章节名、分类名、关卡按钮结构：用公开 Wiki。
- 章节封面 CG：BWiki 画册/剧情回顾公开图，仅非官方展示，版权归库洛。
- 阅读正文：主线普通关使用本地剧情回顾存档对白；间章/活动仍是示例句。不搬语音。
- 品牌：过境 / MINDTRACE，不套官方标识。本地缓存 key 仍为 `mindtrace.*`。演出恢复点为 `mindtrace.play`，不覆盖 notes / readings / progress / danmaku。
- 进站不拉封面图。HOME 预览悬停或点选后再加载。主线目录、封面网格、DATA 立绘、关系网出场表进对应页再拉。STORY 网格和 HOME 封面预览用 `assets/covers/thumbs/`（约 960px JPEG）；关卡页和观看层仍用原图。封面图 `loading=lazy`。不拉 Google Fonts。
